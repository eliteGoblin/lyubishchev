# ADR-007: Feature discipline — few features, good foundation

Date: 2026-08-15. Status: accepted.

## Context

The idea pool is large (output measurement, project hierarchies, agile integrations, UI apps). The original 2022 MVP already warned against scope creep ("不要顺便加上不相干的需求"). Chasing ideas is exactly what competes with rebuilding the habit.

## Decision

Build few features on a good foundation. The critical path is "log a day, query a week": every near-term work item must serve it. Everything else waits in the icebox.

## Consequences

- Roadmap phases 0-2 are the whole committed scope; phases 3-4 follow only after the habit holds.
- New ideas go to `docs/product/ideas.md` by default, not into the roadmap.
